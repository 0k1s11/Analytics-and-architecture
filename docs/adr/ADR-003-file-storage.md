# ADR-003 — File Storage

**Статус:** Accepted  
**Источник:** разделы 4.1, 4.3, 4.9–4.11.

## Решение

Физические файлы хранятся в `./uploads`, а метаданные — в PostgreSQL (`MEDIA_ATTACHMENT`).

### Фото

- 1–10 файлов на подачу;
- JPG/PNG/WebP;
- до 10 МБ;
- backend проверяет MIME и фактический тип содержимого.

### Видео

Видео опционально. Если реализуется:

- максимум 1 файл;
- MP4/WebM;
- до 50 МБ;
- без серверной конвертации, сжатия, нарезки и стриминга.

### Безопасность

- физическое имя генерирует сервер;
- имя клиента хранится только как метаданные;
- путь из request не используется напрямую;
- пользователь не выбирает произвольный путь;
- загрузки находятся вне Git.

## Последствия

Преимущество — простой localhost-запуск без внешнего storage. Ограничение — решение предназначено для MVP и локальной среды.
