# ADR-001 — Architecture Style

**Статус:** Accepted  
**Источник:** разделы 4.2–4.3 исходного аналитического документа.

## Решение

Использовать классическую веб-архитектуру:

- HTML5 + CSS3 + JavaScript ES6+;
- Java 21 + Spring Boot 3.4;
- PostgreSQL 16;
- Hibernate 6 + Spring Data JPA;
- REST/JSON;
- JUnit 5 + Mockito;
- Flyway;
- локальное файловое хранилище `./uploads`.

Backend является основным компонентом бизнес-логики, авторизации, проверки прав, статусов, данных и файлов.

## Причины

- скорость разработки;
- стандартизация REST/JSON;
- строгая типизация Java;
- зрелость PostgreSQL/Hibernate/Flyway;
- простой localhost-запуск без сложной инфраструктуры.

## Ограничения

- внешних сервисов в MVP нет;
- `./uploads` — локальное MVP-хранилище;
- production-ready масштабирование не требуется;
- realtime-чат не реализуется.
